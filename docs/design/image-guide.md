# ขนาดรูปภาพ OneVentOne

ขนาดด้านล่างเป็นขนาดแนะนำสำหรับเตรียมงานออกแบบ ไม่ใช่ข้อบังคับที่ปฏิเสธการอัปโหลด รูป PNG/JPEG/WebP ต้องไม่เกิน 5 MB ระบบไม่ขยายไฟล์เล็กให้ใหญ่ขึ้น และย่อรูปที่ด้านใดด้านหนึ่งเกิน 2,500 px โดยรักษาสัดส่วน

| ตำแหน่ง | ขนาดแนะนำ (กว้าง × สูง) | สัดส่วน | การแสดงผล |
| --- | --- | --- | --- |
| โปสเตอร์ในการ์ดอีเวนท์ หน้าแรกและหน้ารวมงาน | 1,200 × 1,800 px | 2:3 แนวตั้ง | ครอปกึ่งกลางให้เต็มกรอบ ขนาดขั้นต่ำที่แนะนำ 600 × 900 px |
| รูปย่อในผลค้นหา | ใช้โปสเตอร์เดียวกัน | 2:3 | แสดงในกรอบ 48 × 72 CSS px ไม่ต้องเตรียมไฟล์เพิ่ม |
| พื้นหลังหน้ารายละเอียด จอง และบัตรเข้างาน | ใช้โปสเตอร์เดียวกัน | ปรับตามหน้าจอ | ขยาย ครอป และเบลอเป็นบรรยากาศ ไม่ใช้เป็นตำแหน่งอ่านข้อความสำคัญ |
| โลโก้ส่วนหัวเว็บ | 900 × 300 px | 3:1 แนวนอน | แสดงเต็มรูปในกรอบ 150 × 50 CSS px ไม่ครอป ขั้นต่ำที่แนะนำ 300 × 100 px |
| โลโก้ท้ายเว็บ | ใช้โลโก้เดียวกัน | รับได้ทุกสัดส่วน | แสดงเต็มรูปในกรอบ 48 × 48 CSS px จึงอาจมีพื้นที่ว่าง ไม่ต้องเตรียมไฟล์เพิ่ม |
| ภาพปกหน้าแรก `public/concert-hero.png` | 1,920 × 1,080 px | 16:9 แนวนอน | ขยายและครอปตาม viewport มือถือจะเห็นภาพเฉพาะส่วนกลาง ยังเป็นไฟล์ปกคงที่ ไม่ใช่ช่องอัปโหลดในแอดมิน |

## การเตรียมรูป

- โปสเตอร์: เว้นข้อความสำคัญจากขอบอย่างน้อย 8% หลีกเลี่ยงมุมขวาบนที่มีป้ายวันที่ และส่วนล่างที่มีเงาทับภาพ สัดส่วน 2:3 แสดงครบในกรอบเมื่อไม่ได้ hover; การ์ดมีเอฟเฟกต์ซูมเล็กน้อยเมื่อ hover
- โลโก้: ใช้ PNG/WebP โปร่งใส สีอ่านชัดบนพื้นเข้ม และเว้นขอบในไฟล์ 8% โลโก้จัตุรัสยังใช้ได้ แต่ในส่วนหัวจะมีพื้นที่ว่างด้านข้าง
- ภาพปก: ให้วัตถุหลักอยู่ใกล้กึ่งกลาง อย่าใส่ข้อความสำคัญลงในไฟล์ เพราะกรอบเปลี่ยนตามหน้าจอและมีเนื้อหาเว็บทับอยู่
- พรีวิวในแอดมินแสดงกรอบโปสเตอร์และโลโก้ตามสัดส่วนใช้งานจริง พร้อมขนาดไฟล์รูปที่แสดง และคำแนะนำหากความละเอียดต่ำหรือสัดส่วนต่างจากกรอบ
